# 术语表

最后核对：2026-11-23（Asia/Shanghai）

本表是 GUI 术语的**唯一文字来源**。程序内的对应文案保存在 `rust/src/ui_text.rs`，中文与 English 两列同表维护；GUI 首次出现术语时使用本表措辞，同一页面内之后可省略解释。

## 1. 核心术语

| 中文（首次出现） | 中文（之后） | English | 一句话含义 |
|---|---|---|---|
| 试运行（dry-run） | 试运行 | dry run | 只启动 App、浏览页面、读取状态，不点击签到按钮 |
| 正式运行（live） | 正式运行 | live run | 会真实点击签到，必须由你确认并通过全部安全检查 |
| 屏幕预设（Profile） | 屏幕预设 | screen preset | 一组“分辨率 + DPI”，决定签到按钮的坐标；与配置文件无关 |
| 已标定 / 未标定 | 已标定 | calibrated | 该屏幕预设的按钮坐标是否在真机上校准过；正式点击要求已标定 |
| 实例编号（index） | 编号 | index | LDPlayer 给每台虚拟手机分配的整数，从 0 开始 |
| ADB 地址（serial） | ADB 地址 | ADB address | 程序连接实例用的 `127.0.0.1:端口`，不是 `list2` 报告的那个端口 |
| 页面结构（hierarchy） | 页面结构 | page structure | 当前界面的控件树；程序靠它判断页面 |
| 页面 | 页面 | page | 当前停在哪个界面：登录页、首页、服务页、签到页 |
| 签到类型 | 签到类型 | check-in type | 普通晚点名或外勤签到 |
| 签到状态 | 签到状态 | check-in state | 进行到哪一步：等待、定位中、可签到、成功 |
| 运行结果文件（result.json） | 结果文件 | result file | 一次运行的机器可读结果 |
| 运行事件日志（events.jsonl） | 事件日志 | event log | 一次运行的时间线；排查设备或页面问题时先看它 |
| 雷电控制台（ldconsole.exe） | 雷电控制台 | LDPlayer console | LDPlayer 自带的命令行工具，用于查实例、启动实例 |
| 安卓调试工具（adb.exe） | ADB 工具 | ADB tool | 用于连接设备、读取页面与截图 |

## 2. 名词之间的关系

```text
实例（LDPlayer 里的一台虚拟手机）
  ├─ 编号：第几台（0、1、2…）
  ├─ ADB 地址：程序连接它用的地址（127.0.0.1:5555 + 2×编号）
  └─ 屏幕预设：分辨率 + DPI → 决定签到按钮的坐标

一次运行：
  页面（在哪一页）
    → 签到类型（普通晚点名 / 外勤）
    → 签到状态（等待 / 定位中 / 可签到 / 成功）
    → 结果文件（result.json）与事件日志（events.jsonl）
```

实例表里的“雷电报告的端口（list2 报告端口）”只是 LDPlayer 自己报告的参考字段；程序实际用“ADB 地址”连接设备。

## 3. 容易混淆的两组概念

| 容易混淆 | 区别 |
|---|---|
| 屏幕预设 vs 配置文件 | 屏幕预设是“分辨率 + DPI + 按钮坐标”的一组几何参数；配置文件是 `config.toml`，保存程序设置。GUI 导航里分别叫“屏幕预设”和“配置文件（config.toml）”。 |
| 试运行 vs 今天已签到 | 试运行看到“可签到”只说明按钮处于可点击状态；只有程序按成功规则确认当天“签到成功/已签到”文字，才显示“今天已签到”。 |

## 4. 维护规则

- “本页目录”用于跳到当前页面的小节，窄窗口可从正文顶部展开。
- “无法确认签到页面”表示程序缺少足够的页面结构证据，已停止且未点击签到。可在模拟器中核对是否显示“无晚点名清单”。

- 新增或修改用户可见术语时，同时更新本文与 `rust/src/ui_text.rs`；两处措辞必须一致。
- 中文界面使用纯中文（产品名、文件名除外）；English 界面使用纯英文，不在同一句里混排。
- 机器字段（`error_code`、`page_route`、`checkin_state` 等）只出现在“技术详情”折叠区或原始证据里，不作为主界面文案。
