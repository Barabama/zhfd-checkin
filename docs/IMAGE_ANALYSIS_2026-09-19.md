## 代码调整

`scripts/checkin.py` 已从原来的三态“灰/绿/蓝”改为实际页面四态：

```text
gray      -> 等待 120 秒
locating  -> 等待 15 秒
ready     -> 点击“点击签到”
success   -> 报告成功并结束
```

同时修复了：

- App 从锁屏启动时，ColorOS 无密码锁屏需要额外上滑解锁；
- App 保留上次路由、已经停在签到页时不再错误寻找首页入口；
- 手机屏幕关闭时，黑屏不能误判为灰色按钮；
- dry-run 在真实手机上完成了“唤醒/解锁 -> 打开 App -> 进入晚点名签到 -> 识别灰色 -> 不点击”的端到端验证。
