## 冻结决策

### D-01 配置路径与 data root

路径选择优先级：显式 CLI `--config`；存在且有效的 EXE 便携目录 `config.toml`；已存在且有效的 `%LOCALAPPDATA%\ZHFDCheckin\config.toml`；尝试 EXE 便携目录；若便携目录不可写，则进入可见 Setup，引导到固定 LocalAppData root。损坏配置不得静默回退、重置或覆盖，进入 Repair 并展示候选来源。显式 `--config` 的根目录为其父目录。单一 root 统一包含 `config.toml`、`logs/`、`captures/`、`reports/`、`backups/`，不双写。迁移必须先备份，显示源/目标，原子复制并验证后切换；失败留在源 root。

### D-02 ADB sibling 候选

用户选择 `ldconsole.exe` 后自动探测同目录 `adb.exe` 并展示路径/来源/验证状态；这只是候选，不自动写配置。用户确认后才保存，且可单独选择其他 ADB。

### D-03 GUI Setup/Repair 入口

配置缺失进入 Setup；配置语法或字段校验失败进入 Repair；配置有效但共享依赖缺失或验证失败进入依赖 Setup；配置和依赖有效则进入工作台。正常用户每次启动不重复向导，工作台提供可重新进入的 Setup/Repair 入口。

### D-04 首次 dry-run 范围

首次 dry-run 默认选中配置中第一个 enabled 实例（通常 index 0），只运行该实例；GUI 明示当前选择和范围。用户显式选择“全部实例”后才运行所有实例，不要求其余实例先全部通过设备在线检查。

### D-05 多实例失败级联与退出码

共享 preflight（LDPlayer 控制台或 ADB 工具）失败时不启动任何设备，为每个计划实例写入 blocked 结果，并继续生成 run summary。实例专属失败后继续后续实例。存在任何 failed/blocked 时聚合退出码非零；全部完成预期状态才返回零。GUI/CLI 都显示公共 blocker 与逐实例状态。

### D-06 配置备份保留

每次覆盖已存在配置前创建带本地时间戳的备份（格式 `config.toml.bak.YYYYMMDD-HHMMSS`，同秒冲突追加序号）。成功保存后保留最近 5 份，超出部分仅清理更旧备份；失败操作不得清理备份。恢复默认、Repair 应用和 root 迁移都先备份。诊断包默认排除备份；用户显式导出时提示可能含敏感路径和实例信息。

### D-07 公共 preflight 结果结构

每次批量 run 输出一个 run-level `summary.json`，并为每个计划实例保留独立 `result.json`。公共 preflight 失败时结果包含 `run_id`、实例 `index/name/serial`、`status=blocked`、`blocked_by=shared_preflight` 和稳定 `error_code`。保留现有字段并采用向后兼容的可选/默认字段；旧消费者忽略新增字段仍可读取已有字段。

### D-08 hierarchy 不可用与证据冲突

截图视觉只能形成页面候选，不能单独确认 `route=checkin` 或签到模式。hierarchy 不可用但视觉疑似签到页时，使用 `route_candidate_unconfirmed`；视觉与 hierarchy 证据冲突时使用 `route_evidence_conflict`。两者均不得设置 `dry_run_ready` 或授权 live 点击。route、page loading、button state、location state 分开记录；动作后必须重新观测，不得以 `navigated=true` 推断到达。

外勤签到是独立业务模式，不得降级为普通签到。普通 live 默认仍只授权 `Checkin + Ordinary`；如需外勤 live，必须由操作员在当前 `config.toml` 中明确设置 `runtime.allow_field_work_live = true`，同时仍经过 `--live --confirm`、Profile、时间窗、前台、连续 Ready、点击前 route/mode/前台二次复核和全部点击门禁。未知模式永不授权。

### D-09 定位等待

定位等待硬上限 120 秒，轮询周期 2 秒，每 5 秒保存截图或状态摘要。App 离开前台、定位失败、配置签到窗口剩余不足 5 秒或等待到期时立即收敛；到期用稳定错误码 `location_wait_timeout`，保存最后证据。定位中永不点击。Ready 后仍须通过原有全部 live 门禁。

## 实施边界

- 不自动登录、不录入凭据、不绕过 Profile/时间窗/前台/稳定帧门禁。
- 不创建 live 自动任务、不执行真实签到。
- 独立测试 Agent 负责完整动态、集成、设备及 GUI 验收；实现 Agent 仅做必要的开发级构建/静态检查，不宣告独立验收通过。
- 不创建 tag、不 push、不发布；发布须另行明确批准且独立验收通过。
